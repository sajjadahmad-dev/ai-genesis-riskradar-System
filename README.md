# 🚀 RiskRadar AI

> AI-powered business risk intelligence platform using **LLMs**, sentiment analysis, and real-time news monitoring.

---

## 📡 Overview

RiskRadar AI analyzes real-time global news and converts it into actionable business insights using:

- 🤖 LLaMA3-70B (Groq)
- 🌐 SerpAPI News Retrieval
- 📊 Sentiment Analysis
- 🗺 Geospatial Risk Mapping
- 📈 Interactive Analytics Dashboard

The platform helps startups, investors, and businesses identify:

- Market risks
- Economic disruptions
- Growth opportunities
- Disaster-related impacts

---

## 🧠 Key Features

- Real-time news aggregation
- LLM-powered strategic analysis
- Business risk detection
- Investor opportunity insights
- Sentiment analysis dashboard
- Interactive risk maps
- Visual analytics using Plotly

---

## ⚡ Tech Stack

| Category | Technologies |
|---|---|
| Frontend | Streamlit |
| LLM | Groq + LLaMA3-70B |
| News API | SerpAPI |
| NLP | TextBlob |
| Visualization | Plotly |
| Mapping | Folium |
| Data Processing | Pandas |

